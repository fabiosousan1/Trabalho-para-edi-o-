# Editor Magnético N1

Editor de vídeos para Reels, TikTok e Shorts, com foco em uso no celular e notebook.

## Objetivo
Criar uma ferramenta web simples para importar vídeos, pré-visualizar, cortar trechos, adicionar textos e legendas e exportar em 9:16.

## Recursos planejados
- Importação de vídeos e imagens
- Pré-visualização e cortes
- Textos e legendas
- Exportação vertical
- Futuras integrações com IA

## Tecnologias a avaliar
- HTML, CSS e JavaScript para a interface
- FFmpeg para processamento de mídia
- Remotion para composição, respeitando suas condições de licença

## Situação
Projeto inicial. Ainda não existe editor funcional ou hospedagem configurada.
